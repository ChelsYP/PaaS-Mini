Deploy Aplikasi Baru

Jalankan kontainer dari image Docker. Sistem otomatis mengalokasikan domain lokal dan domain publik via NPM.

1. Konfigurasi Utama

3-30 karakter. Hanya huruf kecil, angka, dan tanda hubung (-). Dimulai dengan huruf.

Rute domain yang akan otomatis dibuat:
Publik: https://....chelsa.me
Lokal: http://....paas.local

Tag image spesifik sangat disarankan (contoh: nginx:alpine, bukan latest).

Port aplikasi di dalam kontainer (NPM akan meneruskan lalu lintas web ke port ini). Tidak ada port yang di-expose ke host VM.

2. Alokasi Resource & Jaringan

Kebijakan Otomatis
Memory Limit
256 MB
CPU Quota
0.5 Core
Docker Network
npm_default
Restart Policy
unless-stopped

3. Variabel Lingkungan (Environment)

Konfigurasi runtime opsional yang disuntikkan ke kontainer.
